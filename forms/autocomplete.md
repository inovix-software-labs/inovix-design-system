## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters, Shift+Tab leaves; arrows move suggestion focus; Enter accepts highlight; Escape closes; type-ahead debounces --duration-debounce-input; Ctrl+Space forces open.
- Mouse: hover suggestion highlights --color-brand-soft; click accepts; scroll inside list only; right-click native menu.
- Touch: rows >= --touch-target-min; close on outside tap; no swipe; long-press not used.
- Dismiss: Escape + outside click close; focus returns to the control; no trap without scrim.
- Offline: cache last suggestions, mark --color-warning, replay query on reconnect.
- Debounce: query debounces --duration-debounce-input; pending shows skeleton rows; no double-submit.

Silent by default. Accept -> --sound-click, open -> --sound-click, error -> --sound-error. Haptics: --haptic-light on accept. No sound on typing or hover.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; debounce queries; announce result count via aria; close on Escape with focus return; hold 40% expansion.
Do not: hardcode row height; use color alone; hide the ring; trap focus; autoplay sound; ship without suggestion skeletons; let the list overflow the viewport; fetch inside the control.
Premium treatment: calm field at rest, refined hover as hairline strengthening, tactile accept, crisp ring, graceful disabled, suggestion list enter with --motion-enter and zero layout shift.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- control: role=combobox, aria-expanded, aria-haspopup=listbox, aria-activedescendant, aria-required
- list: role=listbox, aria-label from control
- suggestion: role=option, aria-selected on highlight
- clear: role=button, aria-label clear query, --touch-target-min
- error: role=alert, aria-describedby

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus, never outline:none; ring outside control and highlighted suggestion.
Contrast: AA 4:5:1 label, suggestion text, hint both themes; highlight --color-brand-soft with --color-text-primary 13.40:1; error AA; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Label, hint, error, suggestions: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Suggestion order per locale collation token; query matching locale-aware.
- Plural-safe result count; locale number format.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: value prints with the word chosen in context, error prints with text, no ring, no list, no shimmer.

## 15. Skeleton loader spec (if data-driven, plus skeleton for every sub-shape)

## 16. Icon usage (Lucide names only)

- chevron-down for open, x for clear, search for query affordance, alert-circle for invalid
- Lucide only, --icon-size-md

Lucide line art only, imported by name, never emoji, never custom raster, never icon font.
