## 1. Name + one-line purpose

Name: timepicker. Section: forms. Time capture with hour, minute, second and meridiem fields, step tokens, keyboard spin, locale time format.

## 2. Anatomy (parts, ASCII diagram ok)

```
+-----------------------------------------+
|  [09] : [30] : [00]   [AM]              |
|   ^ v    ^ v     ^ v                    |
+-----------------------------------------+
hint / error
```

- **field group**: hour / minute / second / meridiem sub-fields, --radius-field
- **spin**: Lucide chevron-up / chevron-down per field
- **meridiem**: AM/PM or locale 24h, per locale token
- **hint/error**: --text-xs below

## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters sub-fields; arrows spin value by step; Enter commits; Escape blurs; type digits directly; focus moves to next field on overflow.
- Mouse: hover spin strengthens hairline; click spins; drag not used; right-click native menu.
- Touch: spin targets >= --touch-target-min; long-press not used; swipe not used.
- Dismiss: not applicable.
- Offline: value queued, replayed on reconnect.
- Debounce: commit debounces --duration-debounce-input; async validation pending announced.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; honor locale time format and 12/24h token; pair error with icon + text; hold 40% expansion.
Do not: hardcode step or field width; use color alone; hide the ring; autoplay sound; ship without skeleton; let separators break mid-field.
Premium treatment: calm fields at rest, refined hover as spin highlight, tactile step with --haptic-selection, crisp ring, graceful disabled, loading spinner inside field width so the group never reflows.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- group: role=group, aria-label time per locale
- sub-field: role=spinbutton, aria-valuemin/max/now, aria-required
- meridiem: role=button or native select, aria-pressed
- error: role=alert, aria-describedby

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on focused sub-field, never outline:none.
Contrast: AA 4:5:1 label and sub-field text both themes; error AA; disabled exempt but above 4.5:1 on sunken; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Labels, hint, error, meridiem: externalized, 40% expansion, ellipsis policy.
- Time format per locale token; meridiem names per locale; step names per locale.
- Bidi isolate spans; RTL mirrors field order.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: values print in --font-mono, error prints with text, no ring, no shimmer.

## 16. Icon usage (Lucide names only)

- chevron-up / chevron-down for spin, clock for field affordance, alert-circle for invalid
