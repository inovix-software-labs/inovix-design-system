## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: arrows move by step, PageUp/Down by large step, Home/End to bounds; Tab enters, Shift+Tab leaves; focus ring on thumb.
- Mouse: hover on thumb raises elevation; drag thumb with --cursor-grabbing; click on track jumps; wheel not used; right-click native menu.
- Touch: thumb >= --touch-target-min; long-press not used; swipe along axis only; outside taps do nothing.
- Dismiss: drag cancels on Escape, value restores.
- Offline: value queued, replayed on reconnect.
- Debounce: change event debounces --duration-debounce-input; input event live for bubble only.

## 7. Sound + haptic behavior per event (or explicit silent decision)

Silent by default. Tick crossing -> haptic --haptic-selection only where declared; commit -> --sound-toggle. No sound on hover or drag.

## 8. Responsive Behavior table (mobile/tablet/desktop, what changes, fluid rules)

| Breakpoint | What changes | Rule |
| --- | --- | --- |
| mobile (< --bp-sm) | full-width track, bubble above thumb, ticks hidden | width 100% minus --space-4 gutters |
| tablet (--bp-sm..--bp-lg) | inline track, ticks shown | fluid minmax |
| desktop (>= --bp-lg) | inline, vertical variant where declared | same scale |

Fluid rules: no fixed px; track width fluid; bubble clamps inside viewport; collapse then stack then hide.

## 9. RTL mirror behavior (what flips, what stays)

Thumb travel mirrors along the inline axis; bubble stays above thumb; tick labels align end; no physical left/right.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; announce value via aria-valuenow; clamp bubble inside viewport; hold 40% expansion.
Do not: hardcode track thickness; use color alone for value; hide the ring; ship without ticks where steps exist; autoplay sound; let bubble overflow the viewport.
Premium treatment: calm rail at rest, refined hover as thumb elevation, tactile drag with --ease-decelerate release, crisp ring, graceful disabled, loading spinner on thumb so the track never reflows.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- thumb: role=slider or native input[type=range], aria-valuemin/max/now, aria-valuetext, aria-required
- track: aria-hidden=true, decorative
- bubble: aria-live=polite, off until commit
- error: role=alert, aria-describedby

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus, never outline:none; ring outside thumb.
Contrast: AA 4:5:1 label and bubble both themes; fill --color-primary on sunken rail clears 3:1; error AA; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Label, hint, error, bubble: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Value format per locale number token; step and large-step names per locale.
- Bidi: slider axis mirrors, value stays LTR numeric per locale.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: value prints as text at thumb position, ticks print as hairlines, no ring, no shimmer, no animation.

## 16. Icon usage (Lucide names only)

- none inside the control; optional leading icon per label, Lucide only, --icon-size-md

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text. No icon-only control without accessible name. Directional icons mirror in RTL. If no Lucide glyph fits, the design system owns the gap: file a decision-log entry, do not hand-draw.
