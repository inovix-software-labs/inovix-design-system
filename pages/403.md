## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab reaches actions then policy link; Enter activates; Escape closes request dialog; focus ring on all; S signs in.
- Mouse: hover actions lift --shadow-sm; click sign in goes to auth; click request opens dialog; right-click native menu.
- Touch: actions >= --touch-target-min; tap request opens dialog; swipe not used; long-press copies code.
- Dismiss: Escape closes dialog and clears error; outside tap closes dialog; policy link stays reachable.
- Offline: cached page renders, sign in queued, request action disabled with note, replay on reconnect.
- Debounce: request send debounces --duration-debounce-input; async auth shows button skeleton; policy link load debounces --duration-fast.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- code: role=text, aria-label forbidden code
- illustration: role=img, aria-label locked shield illustration, aria-hidden when decorative
- message: role=text, visible pairing
- actions: role=button and role=link, aria-label sign in and request access
- policy: role=note, aria-label policy note

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on actions and policy link, never outline:none.
Contrast: AA 4.5:1 message, code, action labels, policy note both themes; error --color-error on --color-surface-base verified; focus ring 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Code, message, action labels, policy note: externalized, 40% expansion, ellipsis policy.
- Code digits per locale number format; request state plural-safe per locale.
- Bidi isolate spans; RTL mirrors action order, code digits stay LTR, policy link logical end.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.
