# List

> Purpose: Vertical list of rows with optional selection, action column, empty state and skeleton rows per sub-shape.
> Section: data-display | Theme: light + dark, same tokens | Skeleton: mandatory

## 1. Name + one-line purpose

Name: list. Section: data-display. Vertical list of rows with optional selection, action column, empty state and skeleton rows per sub-shape.

## 2. Anatomy (parts, ASCII diagram ok)

```
+--------------------------+
| (icon) row text    [chev]|
+--------------------------+
| (icon) row text    [chev]|
+--------------------------+
```

- **row**: one item, --text-sm, hover --opacity-hover
- **leading**: optional avatar or icon, --icon-size-md
- **trailing**: optional action or chevron, --touch-target-min
- **divider**: hairline --color-border between rows

## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters first row; arrows move row focus; Enter opens; Space toggles select; Escape clears selection; roving tabindex where declared.
- Mouse: hover row --opacity-hover; click selects; double-click opens; right-click context menu where declared; drag reorder only where declared.
- Touch: rows >= --touch-target-min; swipe row reveals actions; long-press context menu; no hover-only path on coarse pointers.
- Dismiss: context menu closes on Escape + outside; focus returns to row.
- Offline: cached rows render, queue mutations, replay on reconnect, conflict note --color-warning.
- Debounce: filter input debounces --duration-debounce-input; reorder commits at --duration-fast.

## 7. Sound + haptic behavior per event (or explicit silent decision)

Silent by default. Row select -> --sound-click, open -> --sound-click, reorder -> --sound-toggle, error -> --sound-error. Haptics: --haptic-light on select. No sound on hover or scroll.

## 8. Responsive Behavior table (mobile/tablet/desktop, what changes, fluid rules)

| Breakpoint | What changes | Rule |
| --- | --- | --- |

| tablet (--bp-sm..--bp-lg) | two-column grid where listed, meta inline | fluid minmax tokens |

Fluid rules: no fixed px; all widths from --space-* / --measure-* / --bp-* tokens; text wraps, never truncates without ellipsis policy; horizontal scroll only inside scroll-region; collapse then stack then hide, in that order.

Row content aligns start; leading icon stays inline-start; trailing action mirrors to inline-start in RTL; chevron flips; selection stays inline-start; no physical left/right.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep rows >= --touch-target-min; pair status with icon + text; hold 40% expansion; announce selection count.
Do not: hardcode row height; use color alone; hide the ring; trap focus; autoplay sound; ship without row skeletons; let swipe be the only action path.
Premium treatment: calm rows at rest, refined hover as wash never a fill jump, tactile press, crisp ring, graceful disabled rows, loading rows matching final row height with zero shift.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- list: role=list or native ul, aria-label from heading
- row: role=listitem or option, aria-selected when selectable
- action: role=button, accessible name, --touch-target-min
- empty: role=status 'No items'

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on row and action, never outline:none.
Contrast: AA 4:5:1 row text both themes; selected --color-brand-soft with --color-text-primary 13.40:1; error AA; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Row text, empty text, action labels: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Plural-safe row counts; date and number formats per locale tokens.
- Bidi isolate spans; RTL mirrors trailing action.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: fills drop to hairlines, status prints icon + text, no ring, no shimmer, rows print with repeated header where paginated.

## 15. Skeleton loader spec (if data-driven, plus skeleton for every sub-shape)

Skeleton first, content second. Shapes:
- Row: full-width bar at --text-sm height, --color-skeleton-base
- Leading: square --icon-size-md at inline-start, --color-skeleton-base
- Trailing: square --touch-target-min at inline-end, --color-skeleton-base
- Divider: hairline bar, --color-skeleton-base

Fill --color-skeleton-base, shimmer --color-skeleton-shine sweep --duration-slow linear infinite, off under --motion-reduced. aria-busy=true while loading, role=status when content lands. Offline/error: skeleton replaced by state panel per section 3.

## 16. Icon usage (Lucide names only)

- chevron-right for row open, more-vertical for row menu, inbox for empty list
- Lucide only, --icon-size-md

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text. No icon-only control without accessible name. Directional icons mirror in RTL. If no Lucide glyph fits, the design system owns the gap: file a decision-log entry, do not hand-draw.
