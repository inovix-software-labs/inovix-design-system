## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters each control; Enter or Space activates; arrows not used; Escape blurs; focus ring on each control.
- Mouse: hover control washes --color-brand-soft; click activates; drag not used; right-click native menu.
- Touch: controls >= --touch-target-min; long-press not used; swipe not used.
- Dismiss: layer popover closes on Escape + outside; focus returns to layer toggle.
- Offline: controls work offline on cached map, queue view changes, replay on reconnect.
- Debounce: zoom step debounces --duration-fast; async layer load shows skeleton control.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep every control >= --touch-target-min; pair active with aria-pressed; hold 40% expansion; announce zoom level via aria.
Do not: hardcode control size; use color alone; hide the ring; trap focus; autoplay sound; ship without control skeletons; let controls overflow the map.
Premium treatment: calm panel at rest, refined hover as control wash, tactile activate press, crisp ring, graceful disabled, loading control matching final control size with zero shift.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- panel: role=toolbar or group, aria-label map controls
- control: role=button, aria-label + aria-pressed where toggle, --touch-target-min
- layer popover: role=dialog, aria-label layers, closes on Escape
- zoom level: role=status, aria-live=polite for zoom change

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on each control, never outline:none.
Contrast: AA 4:5:1 control labels both themes; active --color-brand-soft with --color-text-primary 13.40:1; error AA; focus 3:1; icon-only controls pair icon + aria-label + tooltip.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Control labels, zoom level text, layer names: externalized, 40% expansion, ellipsis policy.
- Zoom level plural-safe; locale number format.
- Bidi isolate spans; RTL mirrors control stack to inline-start.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.
