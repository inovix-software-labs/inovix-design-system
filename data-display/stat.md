## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: not interactive unless linked; when linked Tab enters link, Enter opens detail, focus ring on link.
- Mouse: hover none on static tile; hover lift --shadow-sm only when linked; click link opens detail; no drag; right-click native menu.
- Touch: link target >= --touch-target-min; long-press previews; no swipe; no hover-only path on coarse pointers.
- Dismiss: not applicable.
- Offline: cached value renders, delta marked --color-warning, replay on reconnect.
- Debounce: value updates debounce --duration-debounce-input; async refresh shows skeleton tile.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep tabular numerals; pair delta with icon + text; hold 40% expansion; announce value changes.
Do not: hardcode value size; use color alone for delta; hide the ring; trap focus; autoplay sound; ship without tile skeleton; let value overflow the tile.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- tile: role=article or region, name from label + value
- value: role=text or meter, aria-valuenow where bounded
- delta: aria-label direction + amount, icon + text never color alone
- link: role=link when linked, accessible name

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on linked control only, never outline:none.
Contrast: AA 4:5:1 label, value, delta both themes; delta pairs icon + text; --color-text-primary on raised verified 20.59:1; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Label, unit, delta text: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Value per locale number format; delta plural-safe; compact notation per locale token.
- Bidi isolate spans; RTL mirrors delta arrow only.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: value prints --font-mono, delta prints with arrow word, no ring, no shimmer, tile prints framed.

## 16. Icon usage (Lucide names only)

- trending-up / trending-down for delta, activity for spark, minus for zero delta
- Lucide only, --icon-size-sm

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text. No icon-only control without accessible name. Directional icons mirror in RTL. If no Lucide glyph fits, the design system owns the gap: file a decision-log entry, do not hand-draw.
