| report title                              date      |
| --------------------------------------------------- |
| table of contents                                 |

## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters toc links; Enter jumps to section; Escape blurs; focus ring on links.
- Mouse: hover toc link underlines --color-accent; click jumps to section; drag selects text; right-click native menu.
- Touch: toc link >= --touch-target-min; long-press previews; swipe scrolls pages.
- Dismiss: not applicable.
- Offline: cached report renders, print queued, replayed on reconnect.
- Debounce: section render debounces --duration-debounce-input; async chart load shows skeleton section.

## 7. Sound + haptic behavior per event (or explicit silent decision)

Silent by default. Section jump -> --sound-click, print -> --sound-success, error -> --sound-error. Haptics: --haptic-medium on section jump. No sound on hover or scroll.

## 8. Responsive Behavior table (mobile/tablet/desktop, what changes, fluid rules)

| Breakpoint | What changes | Rule |
| --- | --- | --- |
| mobile (< --bp-sm) | stack to single column, details vertical | width 100% minus --space-4 gutters |
| tablet (--bp-sm..--bp-lg) | two-column grid, details beside | fluid minmax tokens |
| desktop (>= --bp-lg) | full grid, max --measure-reading | same scale |

Fluid rules: no fixed px; all widths from --space-* / --measure-* / --bp-* tokens; text wraps, never truncates without ellipsis policy; horizontal scroll only inside scroll-region; collapse then stack then hide, in that order.

## 9. RTL mirror behavior (what flips, what stays)

Title and toc align start; body text follows bidi; page numbers stay LTR; sections stack vertically; no physical left/right.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep toc paired with text; hold 40% expansion; print page breaks honored.
Do not: hardcode page break position; use color alone for section state; hide the ring; trap focus; autoplay sound; ship without section skeletons; let title overflow.
Premium treatment: calm report surface at rest, refined hover as toc link underline, tactile jump press, crisp ring, graceful disabled during print, loading sections matching final section heights.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- report: role=document or article, aria-label report title
- toc: role=navigation, aria-label table of contents
- section: role=section, name from heading
- footer: role=contentinfo, name from page number

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on toc links and section headings, never outline:none.
Contrast: AA 4:5:1 title, body, toc both themes; printed state pairs icon + text; error AA; focus 3:1; page numbers never color alone.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Title, section headings, footer: externalized, 40% expansion, ellipsis policy.
- Date and page numbers per locale token; page count plural-safe.
- Bidi isolate spans; RTL mirrors toc link position.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: sections print with breaks, footer prints page number, no ring, no shimmer, report prints framed at --color-border-strong.

## 15. Skeleton loader spec (if data-driven, plus skeleton for every sub-shape)

Skeleton first, content second. Shapes:
- Section: full-width block at section height, --color-skeleton-base
- Toc link: width 50% bar at --text-sm, --color-skeleton-base
- Page break: hairline bar full width, --color-skeleton-base
- Footer: width 20% bar at --text-xs, --color-skeleton-base

Fill --color-skeleton-base, shimmer band --color-skeleton-shine sweep --duration-slow linear infinite, off under --motion-reduced. aria-busy=true while loading, role=status announcement when content lands. Offline/error: skeleton replaced by state panel per section 3.

## 16. Icon usage (Lucide names only)

- file-text for report, book for toc, printer for print mode, alert-circle for error
- Lucide only, --icon-size-md

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text. No icon-only control without accessible name. Directional icons mirror in RTL. If no Lucide glyph fits, the design system owns the gap: file a decision-log entry, do not hand-draw.
