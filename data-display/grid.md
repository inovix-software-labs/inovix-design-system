## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters first cell control; arrows move in grid where declared; Enter activates cell content; Escape clears selection; grid itself not a stop unless interactive.
- Mouse: hover cell washes --opacity-hover; click activates content; drag reorder only where declared with keyboard alternative; right-click native menu.
- Touch: cell controls >= --touch-target-min; swipe not used; long-press previews; no hover-only path on coarse pointers.
- Dismiss: not applicable.
- Offline: cached cells render, queue mutations, replay on reconnect.
- Debounce: reflow debounces --duration-fast on resize; async cell load shows skeleton cell.

## 7. Sound + haptic behavior per event (or explicit silent decision)

Silent by default. Cell action success -> --sound-success, error -> --sound-error. Haptics: --haptic-light on cell select. No sound on hover or reflow.

## 8. Responsive Behavior table (mobile/tablet/desktop, what changes, fluid rules)

| Breakpoint | What changes | Rule |
| --- | --- | --- |
| mobile (< --bp-sm) | stack to single column, hide secondary meta | width 100% minus --space-4 gutters |
| tablet (--bp-sm..--bp-lg) | two-column grid where listed, meta inline | fluid minmax tokens |
| desktop (>= --bp-lg) | full grid, meta inline, max --measure-reading | same scale, no fixed widths |

Fluid rules: no fixed px; all widths from --space-* / --measure-* / --bp-* tokens; text wraps, never truncates without ellipsis policy; horizontal scroll only inside scroll-region; collapse then stack then hide, in that order.

## 9. RTL mirror behavior (what flips, what stays)

Cell order follows DOM and mirrors in RTL; column count unchanged; empty state centers; no physical left/right.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep column counts token-bound; pair empty state with icon + text; hold 40% expansion; reflow without layout jump.
Do not: hardcode column count; use color alone; hide the ring; trap focus; autoplay sound; ship without cell skeletons; let cells overflow the container.
Premium treatment: calm container at rest, refined hover as cell wash, tactile cell press, crisp ring, graceful disabled cells, loading cells matching final cell sizes with zero shift.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- container: role=region or grid, aria-label from heading
- cell: role=gridcell or article, name from content
- empty: role=status 'No items'
- loader: aria-busy=true on container while loading

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on cell controls, never outline:none; container never traps.
Contrast: AA 4:5:1 cell text both themes; empty state text AA; error AA; focus 3:1; container contrast inherits surface tokens.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Heading, empty text, cell content: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Plural-safe cell counts; locale number format inside cells.
- Bidi isolate spans; RTL mirrors cell order.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: cells print framed at --color-border-strong, empty prints icon + text, no ring, no shimmer, no fill waste.

## 15. Skeleton loader spec (if data-driven, plus skeleton for every sub-shape)

Skeleton first, content second. Shapes:
- Cell: 3 bars at cell height, --color-skeleton-base
- Container: full-width block at grid height, --color-skeleton-base
- Empty: square --icon-size-lg centered, --color-skeleton-base

Fill --color-skeleton-base, shimmer --color-skeleton-shine sweep --duration-slow linear infinite, off under --motion-reduced. aria-busy=true while loading, role=status when content lands. Offline/error: skeleton replaced by state panel per section 3.

## 16. Icon usage (Lucide names only)

- inbox for empty grid, layout-grid for container affordance, alert-circle for error
- Lucide only, --icon-size-lg / --icon-size-md

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text. No icon-only control without accessible name. Directional icons mirror in RTL. If no Lucide glyph fits, the design system owns the gap: file a decision-log entry, do not hand-draw.
