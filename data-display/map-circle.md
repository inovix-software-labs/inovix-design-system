## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab reaches legend and table alt; Enter selects circle; arrows move circle focus where declared; Escape closes tooltip; no keyboard path into map pixels.
- Mouse: hover circle lifts --shadow-sm; click selects; scroll zooms with button alternative; drag pans; right-click native menu.
- Touch: pinch zoom optional with buttons; tap circle shows tooltip; pan with drag; targets >= --touch-target-min.
- Dismiss: tooltip closes on Escape + outside + scroll; focus returns to circle.
- Offline: cached circles render, --color-warning marker, queue refreshes, replay on reconnect.
- Debounce: circle select debounces --duration-debounce-input; async value load shows skeleton circles.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- map: role=img, aria-label circle map title + summary, table alt linked
- circle: role=button or gridcell, aria-label name + value, aria-selected
- legend: role=list, items role=listitem, name from size step label
- tooltip: role=tooltip, aria-hidden when closed
- table alt: role=region, aria-label data table

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on legend and circle controls, never outline:none; map pixels never focusable.
Contrast: AA 4:5:1 legend, tooltip, table alt both themes; circle fill pairs with label; error AA; focus 3:1; dark/light swap is the token swap.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Circle names, legend labels, tooltip text: externalized, 40% expansion, ellipsis policy.
- Values per locale number format; step names plural-safe.
- Bidi isolate spans; RTL mirrors legend order.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: circles print as outlined circles with labels, legend prints with text, tooltip not printed, no ring, no shimmer, map prints framed.
