## 2. Anatomy (parts, ASCII diagram ok)

```
+-----------------------------------------+
| brand        link   link   [actions]      |
+-----------------------------------------+
```

## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab reaches brand then links then actions, Enter activates link, skip to content on first tab.
- Mouse: hover link underlines --color-accent, click activates, brand click home, no drag.
- Touch: targets >= --touch-target-min, long-press not used, hamburger toggle opens menu.
- Dismiss: not applicable, persistent bar.
- Offline: links cached, hover states instant.
- Debounce: scroll stickiness debounce --duration-fast, async brand skeleton navbar.

## 11. Do / Do not list

Do: reference tokens; skip to content on first tab; label menu toggle; underline hover not color alone; hold 40% expansion.
Do not: hardcode bar height; hide the ring; trap focus; autoplay sound; fixed px widths; let links overflow bar.
Premium treatment: premium sticky entry with --shadow-md on scroll, crisp ring, zero layout shift on open.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- container: role=navigation, aria-label site navigation
- brand: role=link, aria-label brand home
- nav links: role=link, accessible name
- actions: role=button, accessible name
- menu toggle: role=button, aria-expanded, aria-label open menu

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on focused link or action, never outline:none.
Contrast: AA 4.5:1 links and brand both themes; hover underline 3:1; focus ring 3:1; --color-text-primary on --color-surface-raised verified.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Link labels, brand, action text: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Link order per locale token.
- Bidi isolate spans; RTL mirrors bar order and inline edges.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

Prints bar as text block, links as text, no ring or shadow, no interactive states.
