## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters sliders and hex; arrows move hue/alpha by step; Enter commits hex; Escape blurs; swatches reachable by grid arrows.
- Mouse: drag slider thumb with --cursor-grabbing; click swatch selects; click hex commits; no drag of swatch.
- Touch: thumbs >= --touch-target-min; swipe not used; long-press previews; outside taps do nothing.
- Dismiss: not applicable.
- Offline: value queued, replayed on reconnect.
- Debounce: hex input debounces --duration-debounce-input; async palette load shows skeleton swatches.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep swatches token-bound; announce value via aria; hold 40% expansion.
Do not: hardcode slider height; use color alone; hide the ring; autoplay sound; ship without swatch skeleton; let hex overflow; use a non-token palette.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- hue: role=slider, aria-valuemin/max/now, aria-valuetext hue
- alpha: role=slider, aria-valuetext alpha percent
- swatch: role=button or gridcell, aria-label color name + hex
- hex: role=textbox, aria-label hex value, aria-describedby error
- preview: role=img, aria-label current color

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on sliders, hex and swatch, never outline:none.
Contrast: AA 4:5:1 label, hex text, hint both themes; error AA; focus 3:1; swatch labels pair name + value, never color alone.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Labels, hint, error, color names: externalized, 40% expansion, ellipsis policy.
- Hex stays LTR; color names per locale token; alpha percent per locale number format.
- Bidi isolate spans; RTL mirrors slider direction.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: swatches print as named patches with hex text, error prints with text, no ring, no shimmer.

## 16. Icon usage (Lucide names only)

- no icons inside sliders; optional eyedropper for hex capture, alert-circle for invalid
- Lucide only, --icon-size-md

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text.
