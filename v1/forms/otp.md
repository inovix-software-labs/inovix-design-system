## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: digits type in; Backspace retreats; arrows move between cells; paste fills all; Escape clears; Enter submits; Tab enters and leaves the group.
- Mouse: click cell focuses it; hover strengthens hairline; no drag; right-click native menu.
- Touch: cells >= --touch-target-min; long-press not used; swipe not used; numeric keyboard via inputmode.
- Dismiss: not applicable.
- Offline: code queued, verified on reconnect, resend timer holds.
- Debounce: resend timer debounces --duration-toast; async verify pending announced via aria-busy.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; announce position and filled count via aria; pair error with icon + text; hold 40% expansion.
Do not: hardcode cell size; use color alone; hide the ring; autoplay sound; ship without cell skeletons; let paste overflow; use a non-mono digit face.
Premium treatment: calm cells at rest, refined hover as hairline strengthening, tactile digit entry with --haptic-selection, crisp ring on active cell, graceful disabled, loading spinner inside group width.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- group: role=group, aria-label one-time passcode, aria-required
- cell: role=textbox, aria-label position n of total, aria-invalid on error
- resend: role=button, aria-label resend code, disabled while timer runs
- error: role=alert, announced once

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on active cell, never outline:none.
Contrast: AA 4:5:1 label, digits, resend both themes; error AA; disabled exempt but above 4.5:1 on sunken; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Label, hint, error, resend text: externalized, 40% expansion, ellipsis policy.
- Timer text per locale number format; digits stay LTR.
- Bidi isolate spans; RTL mirrors resend position.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: digits print in --font-mono, error prints with text, no ring, no shimmer, timer prints as text.
