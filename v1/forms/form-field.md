# Form Field

> Purpose: Field wrapper: label, control slot, hint, error, required marker and action slot, the shared shell every form control renders inside.
> Section: forms | Theme: light + dark, same tokens | Skeleton: mandatory

## 1. Name + one-line purpose

Name: form-field. Section: forms. Field wrapper: label, control slot, hint, error, required marker and action slot, the shared shell every form control renders inside.

## 2. Anatomy (parts, ASCII diagram ok)

```
+---------------------------------------------------+
| Label (required marker)                           |
| +-----------------------------------------------+ |
| | control slot                                  | |
| +-----------------------------------------------+ |
| hint  /  error  /  action                        |
+---------------------------------------------------+
```

- **label**: for/id link, --text-sm --weight-medium, required marker token
- **control**: child control slot, tokens only
- **hint**: --text-xs --color-text-secondary, never error-colored at rest
- **error**: role=alert inline, icon + text, --color-error
- **action**: optional clear/reveal/count, --touch-target-min, never the only path

## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: label click focuses child via for/id; actions reachable by Tab; Escape clears only where declared; no extra stop.
- Mouse: hover none on wrapper; label click focuses child; action click runs action; right-click native menu.
- Touch: action target >= --touch-target-min; long-press not used; swipe not used.
- Dismiss: not applicable.
- Offline: child state owns queue; wrapper renders cached value with marker.
- Debounce: child owns debounce; wrapper only relays state.

## 7. Sound + haptic behavior per event (or explicit silent decision)

Silent by default. Wrapper makes no sound; child events use child tokens. Haptics none. Sound policy belongs to the child control.

## 8. Responsive Behavior table (mobile/tablet/desktop, what changes, fluid rules)

| Breakpoint | What changes | Rule |
| --- | --- | --- |
| mobile (< --bp-sm) | label above control, full width, hint below | width 100% minus --space-4 gutters |
| tablet (--bp-sm..--bp-lg) | label above, two-column field grid where listed | fluid minmax tokens |
| desktop (>= --bp-lg) | inline label + control, max --measure-reading | same grid, no fixed widths |

Fluid rules: no fixed px; all widths from --space-* / --measure-* / --bp-* tokens; text wraps, never truncates without ellipsis policy; horizontal scroll only inside scroll-region; collapse then stack then hide, in that order.

## 9. RTL mirror behavior (what flips, what stays)

Label and control keep DOM order; text-align start; error icon sits inline-end; action mirrors to inline-start in RTL; no physical left/right.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep one label per control; pair error with icon + text + aria-describedby; hold 40% expansion; never add chrome the child does not declare.
Do not: hardcode a gap or height; use placeholder as the only label; trap focus; hide the ring; autoplay sound; ship without skeleton; stack two labels on one control.
Premium treatment: calm wrapper with zero chrome of its own, refined hover inherited from child, tactile press inherited, crisp ring on child only, graceful disabled at --opacity-disabled, loading matches child layout with zero shift.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- label: for/id link, accessible name, aria-required when required
- control: child role, aria-invalid on error, aria-describedby hint + error
- hint: aria-hidden=false, referenced by describedby
- error: role=alert, announced once
- action: role=button, aria-label, --touch-target-min

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus lands on the child control, never the wrapper; wrapper never removes it.
Contrast: AA 4:5:1 label, hint, error both themes; error AA on raised; disabled exempt but above 4.5:1 on sunken; focus 3:1 on child.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Label, hint, error, action label: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Required marker per locale token; plural-safe counts.
- Bidi isolate spans; RTL mirrors action position.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: error prints with text, borders print --color-border-strong, no ring, no shimmer, value prints --font-mono where numeric.

## 15. Skeleton loader spec (if data-driven, plus skeleton for every sub-shape)

Skeleton first, content second. Shapes:
- Label: width 30% bar at --text-sm, --color-skeleton-base
- Control slot: full-width block at child height, --color-skeleton-base
- Hint: width 60% bar at --text-xs, --color-skeleton-base
- Action: square --touch-target-min at inline-end, --color-skeleton-base

Fill --color-skeleton-base, shimmer --color-skeleton-shine sweep --duration-slow linear infinite, off under --motion-reduced. aria-busy=true while loading, role=status when content lands. Offline/error: skeleton replaced by state panel per section 3.

## 16. Icon usage (Lucide names only)

- asterisk for required marker, alert-circle for error, x for clear action
- Lucide only, --icon-size-sm

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text. No icon-only control without accessible name. Directional icons mirror in RTL. If no Lucide glyph fits, the design system owns the gap: file a decision-log entry, do not hand-draw.
