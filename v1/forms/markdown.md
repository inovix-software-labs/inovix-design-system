## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab enters toolbar then field; arrows move caret; Ctrl+Enter toggles preview; Escape blurs; markdown shortcuts native to field.
- Mouse: hover toolbar washes --color-brand-soft; click toggles mode; select-all native; right-click native menu.
- Touch: targets >= --touch-target-min; long-press selects; swipe not used; field scrolls natively.
- Dismiss: not applicable.
- Offline: source queued locally, replayed on reconnect, preview from cache.
- Debounce: preview render debounces --duration-debounce-input; async macro load shows skeleton preview.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep preview inside viewport; announce mode change via aria; hold 40% expansion.
Do not: hardcode field height; use color alone; hide the ring; trap focus; autoplay sound; ship without preview skeleton; let preview inject raw markup.
Premium treatment: calm field at rest, refined hover as toolbar wash, tactile toggle, crisp ring, graceful disabled, loading preview matching final height with zero shift.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- toolbar: role=toolbar, aria-label markdown mode, roving tabindex
- field: role=textbox aria-multiline=true, aria-label markdown source, aria-describedby hint + error
- preview: role=region, aria-label preview, aria-live=polite
- error: role=alert, announced once

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on toolbar and field, never outline:none.
Contrast: AA 4:5:1 label, preview text, hint both themes; error AA; focus 3:1; preview headings pair with text, never style alone.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Toolbar labels, hint, error, mode names: externalized, 40% expansion, ellipsis policy.
- Preview content follows locale date, number and plural tokens; CJK/Thai break rules.
- Bidi isolate spans; RTL mirrors toolbar order.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: preview prints without fills, error prints with text, no ring, no shimmer, code prints --font-mono.
