## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab reaches link; Enter opens details; Escape dismisses where declared; line itself not focusable.
- Mouse: hover link underlines --color-accent; click opens details; no drag; right-click native menu.
- Touch: link target >= --touch-target-min; long-press not used; swipe not used.
- Dismiss: clear action removes line and announces via role=status; focus stays on field.
- Offline: cached error text renders, queue clear, replay on reconnect.
- Debounce: error updates debounce --duration-debounce-input; announce once per new error only.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- line: role=alert, announced once, name from icon + text
- icon: aria-hidden=true, decorative
- link: role=link, accessible name, --touch-target-min
- clear: role=button when dismissible, aria-label clear error

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on link only, never the text line; never outline:none.
Contrast: AA 4:5:1 error text both themes (verified in theme-variables.md contrast table); link --color-accent on raised 15.69:1 light; icon pairs with text; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Error text: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Plural-safe error counts; locale number format inside text.
- Bidi isolate spans; RTL mirrors link position.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

Grayscale readable: error prints bold text with the word error, icon prints as the word alert, no ring, no shimmer, link prints underlined.
