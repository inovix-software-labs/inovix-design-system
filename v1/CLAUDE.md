# Instructions for AI coding agents

This folder is the Inovix design system. If you were asked to build an app, page or component with it:

1. Open README.md in this folder before anything else and follow its MUST checklist and reading order.
2. Then read theme-variables.md, brand/logo.md, brand/logo-responsive.md, and the layout/ files (holy-grail, header, sidebar, footer, main-content).
3. Then read only the component files the requirement needs.
4. Do not read REQUIREMENTS.MD or .git. Do not read every file.
5. Your output is real code in the format requested (for example one index.html). Use the CSS variables and sRGB fallbacks from theme-variables.md exactly, load Inter, DejaVu Sans (logo only) and Lucide from the pinned CDN sources listed there, and ship both light and dark themes.
