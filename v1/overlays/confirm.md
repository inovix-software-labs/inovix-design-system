## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab cycles confirm then cancel, Enter confirms, Escape cancels and returns focus, focus trap active.
- Mouse: click confirm commits, click cancel dismisses, scrim tap cancels unless declared, no drag.
- Touch: button targets >= --touch-target-min, scrim tap cancels where declared, swipe not used.
- Dismiss: Escape + cancel + scrim tap, focus returns to trigger, choice announced politely.
- Offline: choice queued, replayed on reconnect.
- Debounce: confirm debounce --duration-fast, no double-submit.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- container: role=dialog, aria-modal=true, aria-labelledby title
- title: id referenced by aria-labelledby on container
- confirm: role=button, aria-label confirm action, --touch-target-min
- cancel: role=button, aria-label cancel action, --touch-target-min
- scrim: aria-hidden=true behind the dialog

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on the focused button inside the confirm, never outline:none.
Contrast: AA 4.5:1 title and body on overlay both themes; buttons 3:1; focus ring 3:1; --color-text-primary on --color-surface-overlay verified.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Title, body, confirm label, cancel label: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Confirm and cancel announcements per locale token.
- Bidi isolate spans; RTL mirrors close and action positions.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.
