## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab reaches search then actions; Enter submits search; Escape clears search; H goes home; R opens report link; focus ring on all.
- Mouse: hover actions lift --shadow-sm; click search submits; click report opens; drag not used; right-click native menu.
- Touch: search and actions >= --touch-target-min; tap search opens keyboard; swipe not used; long-press copies code.
- Dismiss: Escape clears search and closes report; outside tap closes report; home action always reachable.
- Offline: cached page renders, search disabled with note, home action kept, queued report replays on reconnect.
- Debounce: search submit debounces --duration-debounce-input; async results show skeleton rows; report sends show button skeleton.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- code: role=text, aria-label not found code
- illustration: role=img, aria-label broken link illustration, aria-hidden when decorative
- message: role=text, visible pairing
- search: role=searchbox, aria-label search the site
- actions: role=button and role=link, aria-label home and report

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on search and actions, never outline:none.
Contrast: AA 4.5:1 message, code, action labels both themes; error --color-error on --color-surface-base verified; focus ring 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Code, message, search placeholder, action labels, report copy: externalized, 40% expansion, ellipsis policy.
- Code digits per locale number format; message plural-safe per locale.
- Bidi isolate spans; RTL mirrors action order, code digits stay LTR, report link logical end.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.
