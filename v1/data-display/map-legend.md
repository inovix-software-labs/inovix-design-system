## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab reaches collapse; Enter toggles; arrows scroll rows; Escape blurs; focus ring on collapse.
- Mouse: hover row washes --opacity-hover; click collapse toggles; drag not used; right-click native menu.
- Touch: collapse >= --touch-target-min; long-press previews; swipe not used.
- Dismiss: collapse closes legend; focus returns to trigger.
- Offline: cached legend renders, queue updates, replay on reconnect.
- Debounce: band update debounces --duration-debounce-input; async legend load shows skeleton rows.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep swatch paired with label; hold 40% expansion; announce collapse via aria-expanded.
Do not: hardcode row height; use color alone; hide the ring; trap focus; autoplay sound; ship without row skeletons; let labels overflow the legend.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- legend: role=list or region, aria-label map legend
- row: role=listitem, name from swatch + label
- collapse: role=button, aria-expanded, aria-label collapse legend
- layer: role=text, aria-hidden=false

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on collapse, never outline:none.
Contrast: AA 4:5:1 labels, layer name both themes; band swatches pair with labels; error AA; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Labels, layer name, collapse label: externalized, 40% expansion, ellipsis policy.
- Band values per locale number format; plural-safe band counts.
- Bidi isolate spans; RTL mirrors collapse position.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: swatches print as outlined patches with labels, collapse prints as word expand/collapse, no ring, no shimmer, legend prints framed.

- chevron-up / chevron-down for collapse, legend for legend affordance, alert-circle for error
- Lucide only, --icon-size-sm / --icon-size-md

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text.
