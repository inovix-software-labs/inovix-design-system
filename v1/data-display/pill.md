## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: not focusable when static; when linked, Tab enters link, Enter opens, focus ring on link.
- Mouse: hover none on static; hover underline on linked pill; click link opens; no drag; right-click native menu.
- Touch: linked pill target >= --touch-target-min; long-press previews; swipe not used.
- Dismiss: not applicable.
- Offline: cached status renders, queue updates, replay on reconnect.
- Debounce: status updates debounce --duration-debounce-input; pulse once per new status.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; pair every status with icon + text; hold 40% expansion; announce status changes via aria-live.
Do not: hardcode pill height; use color alone; hide the ring on linked pills; autoplay sound; ship without skeleton; let text overflow the pill.
Premium treatment: calm pill at rest, refined hover as fill strengthen never a color jump, crisp ring on linked pills, graceful disabled at --opacity-disabled, loading pill matching final width.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- pill: role=status or img, name from icon + text, aria-live=polite for status
- icon: aria-hidden=true when decorative
- link: role=link when linked, accessible name, --touch-target-min

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on linked pill only, never outline:none.
Contrast: AA 4:5:1 text on every semantic fill both themes (verified in theme-variables.md contrast table); icon pairs with text; focus 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Status text, label: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Status names plural-safe per CLDR category, locale number format.
- Bidi isolate spans; icon never flips, only layout mirrors.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: fill drops to outline, status prints as word, icon prints as the word status, no shimmer, no ring.

## 16. Icon usage (Lucide names only)

- check-circle-2 for success, alert-triangle for warning, x-circle for error, info for info, minus for neutral
- Lucide only, --icon-size-sm

Lucide line art only, imported by name, never emoji, never custom raster, never icon font. Size from --icon-size-sm/md/lg/xl; stroke from --icon-stroke-thin/regular/thick; color from --color-text-secondary / state tokens; aria-hidden=true on decorative icons, meaningful icons carry aria-label or visible text. No icon-only control without accessible name. Directional icons mirror in RTL. If no Lucide glyph fits, the design system owns the gap: file a decision-log entry, do not hand-draw.
