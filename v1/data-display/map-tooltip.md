## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab reaches close and rows; Enter activates row link; Escape closes and returns focus; arrows scroll rows; focus trap inside while open.
- Mouse: hover row washes --opacity-hover; click row link follows; click outside closes; drag not used; right-click native menu.
- Touch: close >= --touch-target-min; tap outside closes; long-press not used; swipe not used.
- Dismiss: Escape + outside click + scroll close; focus returns to the anchor point; no trap without scrim.
- Offline: cached point data renders, queue refresh, replay on reconnect.
- Debounce: anchor move debounces --duration-fast; async point load shows skeleton rows.

## 11. Do / Do not list

Do: reference tokens; ship all 26 states; keep panel inside viewport; announce open via aria; hold 40% expansion; return focus to anchor on close.
Do not: hardcode panel width; use color alone; hide the ring; trap focus without scrim; autoplay sound; ship without row skeletons; let panel overflow the viewport.
Premium treatment: calm overlay panel at rest, refined hover as row wash, tactile close press, crisp ring, graceful disabled, loading rows matching final row heights with zero shift.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- panel: role=tooltip or dialog, aria-label point tooltip, aria-hidden when closed
- title: role=text, name from point title
- row: role=row, name from label + value
- close: role=button, aria-label close tooltip, --touch-target-min

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on close and row links, never outline:none.
Contrast: AA 4:5:1 title, row labels, values both themes; error AA; focus 3:1; values pair with labels, never color alone.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Title, row labels, close label: externalized, 40% expansion, ellipsis policy.
- Values per locale number format; row counts plural-safe.
- Bidi isolate spans; RTL mirrors close position.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.

## 14. Print behavior

Grayscale readable: rows print with borders, close prints as word close, error prints with text, no ring, no shimmer, panel prints framed.
