## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: not interactive, focus passes through to surface controls.
- Mouse: click passes to surface unless dismiss declared, hover none.
- Touch: tap dismisses where declared, swipe not used.
- Dismiss: tap or Escape where declared, no focus trap.
- Offline: scrim state cached, reapplied on reconnect.
- Debounce: appear and disappear debounce --duration-fast.

## 11. Do / Do not list

Do: reference tokens; cover viewport; honor dismiss policy; never trap focus; hold 40% expansion.
Do not: hardcode viewport size; use color alone for state; trap focus on scrim; autoplay sound; let clicks leak through undeclared.
Premium treatment: premium soft fade via --ease-standard, crisp edge under surface, no vibration on appear.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- layer: aria-hidden=true behind the surface
- click-target: role=button, aria-label dismiss scrim when dismiss declared
- stack: role=presentation, no accessible name

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on host controls only, scrim never focuses, never outline:none.
Contrast: Scrim is decorative and exempt, host surface AA 4.5:1 both themes; focus ring 3:1.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Dismiss label: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Scrim appear announcements per locale token where dismiss exists.
- Directionless layer, no mirroring in RTL.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.
