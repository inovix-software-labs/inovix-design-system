## 5. Behavior + interaction rules (keyboard, mouse, touch, dismiss, debounce, drag, long-press, right-click)

- Keyboard: Tab moves into content, PageUp or PageDown scrolls region.
- Mouse: hover none, scroll wheel scrolls region, drag thumb.
- Touch: native scroll, swipe inside region.
- Dismiss: not applicable, persistent region.
- Offline: content cached, renders instantly.
- Debounce: scroll end debounce --duration-fast, async content skeleton region.

## 11. Do / Do not list

Do: reference tokens; keep scroll inside region; label viewport; announce scroll; hold 40% expansion.
Do not: hardcode height; trap focus in region; autoplay sound; let content overflow region; fixed px padding.
Premium treatment: premium calm region with crisp ring, zero layout shift on resize.

## 12. Accessibility requirements (role, aria, focus, contrast, screen reader, reduced motion, high contrast, forced colors)

Per-part aria mapping:
- container: role=region, aria-label scroll region
- viewport: role=region, aria-label viewport
- track: aria-hidden=true, visual only
- thumb: aria-hidden=true, visual only
- corner: aria-hidden=true, visual only

Focus: :focus-visible ring --shadow-focus-glow + 2 units --color-border-focus on content controls only, never outline:none.
Contrast: AA 4.5:1 content text both themes; focus ring 3:1; --color-text-primary on --color-surface-base verified.

## 13. i18n requirements (text expansion, bidi, script, plural, locale format)

- Region label: externalized, 40% expansion, ellipsis policy, no mid-word break.
- Scroll announcements per locale token.
- Bidi isolate spans; RTL mirrors scroll start.

All strings externalized to locale files; zero literals in code. Layouts hold 40% expansion from en without truncation, overlap, or fixed heights. Bidi: Unicode algorithm, isolate spans, no concatenated mixed-direction strings. Scripts: Latin/Cyrillic/Greek first with CJK/Devanagari/Arabic fallback stacks from --font-ui; per-script line-height via --leading-* tokens, never fixed px. Plurals: CLDR categories with count token, never hardcoded suffix. Formats: date, time, number, currency, calendar, first-day-of-week, timezone all per locale token; store UTC, label always shown. RTL: full mirror per section 9. Truncation: ellipsis token policy only, never mid-word, tooltip on truncated. Hyphenation: off unless token enables per locale. Line breaking: CJK/Thai rules, no overflow hidden on text.
